# tkinter-desktop-pet-test

A desktop pet program developed with Python tkinter, featuring Yuan Ji, a noble from the Eastern Han Dynasty.

## Project Introduction

This is an interactive desktop pet program that can:
- Move freely on the desktop
- Interact with users
- Support AI conversations
- Provide sound feedback
- Auto-save chat history

1. Python 3.7+

3. LM Studio (for AI chat)
   - Download [LM Studio](https://lmstudio.ai/)
   - Run local server (port 1234)

## Basic Operations

- Left-click drag: Move pet
- Left-click: Pet moves toward click direction
- Right-click: Open chat window
- Mouse proximity: Pet reacts
- No operation for 40s: Enter waiting state

## Common Issues

1. Program won't start
   - Check Python version (3.7+)
   - Verify all dependencies installed
   - Check all resource files exist

2. No animations
   - Verify Gif folder contents
   - Check file names

3. No sound
   - Check sound files in sounds folder
   - Verify system audio working

4. Chat not responding
   - Ensure LM Studio is running
   - Check port 1234 availability
